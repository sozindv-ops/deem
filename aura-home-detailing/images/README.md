# Фотографии разделов AURA

Положите сюда файлы с этими именами — они автоматически подставятся
в соответствующие разделы сайта. Пока файла нет, показывается временное
стоковое фото (fallback), а если и оно недоступно — текстурная подложка.

| Файл                | Раздел на сайте                      | Что на фото (по загруженным изображениям) |
|---------------------|--------------------------------------|-------------------------------------------|
| `aura-stone.jpg`    | Услуги → **AURA Stone**              | Стена из сине-красного оникса/мрамора      |
| `aura-wood.jpg`     | Услуги → **AURA Wood**               | Деревянные панели, ТВ-зона                 |
| `aura-textile.jpg`  | Услуги → **AURA Textile**            | Бежевый диван, полупрозрачные шторы        |
| `aura-leather.jpg`  | Услуги → **AURA Leather**            | Оранжевый кожаный диван-реклайнер          |
| `aura-glass.jpg`    | Услуги → **AURA Glass & Facades**    | Шале, спортзал за стеклянной перегородкой  |
| `aura-kitchen.jpg`  | Услуги → **AURA Kitchen & Bath**     | Мраморный кухонный остров                  |
| `hero.jpg`          | Главная → **первый экран (hero)**    | Гостиная на закате, панорамные окна        |

Рекомендуемый размер: ширина 1600–2000 px, формат JPG/WebP.
